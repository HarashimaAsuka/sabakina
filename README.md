企画概要
大学の授業内にてサバキナという言葉を与えられ、その意味を持たない言葉から内容を考えてゲームを制作するという課題でできた作品です。私たちのグループはサバキナという言葉を、サバイバル機内と考え、制作したリズムゲームとなっています。私はエンジニアとして制作に関わりました。
このゲームは飛行機とエイリアンのワープ装置が衝突し降下中の飛行機内で、主人公が墜落を阻止するために逃げてくる乗客を助け、ワープゲートから流れてくるエイリアンを倒していくゲームです。
敵をタイミングよくボタンを押して攻撃することでゲームを進めていきます。常に高度は下がり続けますが、Miss をすると落下速度が上昇します。高度が 0 になるとゲームオーバーになります。
